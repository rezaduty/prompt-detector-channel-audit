# Datasets

Two datasets are used. One is released here, one is read from its publisher.
Neither is generated by a language model.

---

## 1. The probe set (released here)

`probes/probes.jsonl`, 91 items, one JSON object per line.

### Purpose

A diagnostic set, not a sample of traffic. It exists to separate two questions
that an ordinary attack corpus conflates:

- is this text an **attack**?
- is this text **prompt shaped**, that is, a prompt artifact of any kind?

A legitimate system prompt is prompt shaped and benign. An injection typed into
a chat box is an attack and is not prompt shaped. Corpora that contain only
attacks and ordinary questions cannot tell a detector that fires on attacks
apart from one that fires on instruction-like writing, because in those corpora
the two coincide.

### Schema

| field | type | meaning |
| --- | --- | --- |
| `id` | string | stable identifier, e.g. `s5_dec_02` |
| `text` | string | the probe |
| `true_label` | `S5` \| `S6` \| `SAFE` | taxonomy label, see *Composition* |
| `phrasing` | string | surface-form group, see *Composition* |
| `is_prompt` | bool | whether the text is a prompt artifact |

`true_label` follows the taxonomy of the detector under measurement, served by
its `GET /api/prompt-scans/guard-prompt` endpoint and reproduced in the paper:
`S5` prompt injection, `S6` jailbreak, `SAFE` neither.

### Composition

| label | phrasing | n | prompt shaped | what it is |
| --- | --- | --: | --: | --- |
| S5 | `imperative` | 15 | 0 | direct override command |
| S5 | `declarative` | 14 | 0 | instruction asserted as a statement of fact |
| S5 | `indirect` | 10 | 0 | payload arriving as retrieved or tool-returned content |
| S6 | `roleplay` | 8 | 0 | persona jailbreaks |
| S6 | `encoding` | 4 | 0 | encoding and mode-marker jailbreaks |
| SAFE | `benign` | 20 | 0 | ordinary requests |
| SAFE | `legit_prompt` | 8 | 8 | **hard negative**: real system prompts |
| SAFE | `security_doc` | 8 | 0 | **hard negative**: benign text quoting attack vocabulary |
| SAFE | `benign_template` | 4 | 4 | **hard negative**: benign text with unfenced placeholders |
| | **total** | **91** | **12** | |

### The hard negatives are the point

Twenty of the forty benign probes are chosen so that a detector relying on one
surface feature rather than on intent will fire on them. A plain accuracy
figure over attacks and ordinary questions hides that reliance.

- `legit_prompt` is instruction-shaped and benign. A detector that treats
  instruction-like text as an attack fails on this group.
- `security_doc` quotes attack vocabulary in benign text, for example a
  sentence explaining that injection attacks begin with the phrase *ignore
  previous instructions*. A detector keyed on vocabulary rather than intent
  fails on this group.
- `benign_template` carries unfenced `{placeholder}` syntax with no attack
  content.

### Length is held constant on purpose

Attack probes average 72.8 characters and benign probes 63.1, and length alone
separates the classes at an AUROC of 62.4%. This is deliberate. In the external
corpus described in section 2, injections are more than twice as long as
benign items and length alone separates them at 79.3%, which is enough for a length-sensitive scorer to
look skilful without doing the task. Holding length roughly equal removes that
shortcut so the phrasing and prompt-shapedness axes carry the comparison.

### Provenance and known limitations

- Written by the author from attack phrasings published in the prior work cited
  in the paper. No text is model-generated.
- **Labelled by a single annotator.** There is no inter-annotator agreement
  figure, and the labels reflect one reading of the deployed taxonomy.
- **Group sizes are small.** Several groups hold 4 to 8 items. Per-group rates
  carry wide Wilson intervals and should be read as directional unless a
  significance test is quoted alongside.
- Base rates are not realistic. Benign items are 40 of 91, while real traffic
  is overwhelmingly benign, so the false-positive rates measured on this set
  translate into worse precision in deployment.
- Payloads are **not adaptive**. Nothing was optimised against the detector, so
  every detection rate is an upper bound.

### Regenerating

    python3 src/build_probes.py

The generator embeds every probe as a literal, so the set is reproducible with
no network access and the file in this repository is exactly what it emits.

### Ethics

Every probe is benign in effect. The attack probes use canary-style payloads
that request a marker string or describe a policy permitting disclosure. None
carries harmful content, and no third-party service was exercised in producing
or evaluating them.

## 2. The external corpus (not redistributed)

The test split of **deepset/prompt-injections**, 116 items, 60 labelled as
injection and 56 as benign, published by deepset under CC-BY-4.0:

<https://huggingface.co/datasets/deepset/prompt-injections>

It is read from the local Hugging Face dataset cache at run time and is **not
copied into this repository**. Labels are the publisher's, not ours. It is used
to repeat the channel comparison on text written and labelled by people
unconnected to this work.

To make it available:

```python
from datasets import load_dataset
load_dataset("deepset/prompt-injections")
```

Then set `external_dataset_glob` in `config.json` if your cache is elsewhere.

### One caveat that constrains the comparison

The trained guard evaluated in the paper was fine tuned on 60 rows drawn from
this same corpus, and the serving stack does not record which rows. Overlap
between its training data and this test split therefore cannot be ruled out,
and its numbers on the external split are an optimistic bound. The rule
channels and the zero-shot guard have no training data at all, so for them this
corpus is a clean external test. The paper states this wherever those numbers
appear.

## 3. NotInject (redistributed, MIT)

`external/notinject.jsonl`, 339 benign prompts, frozen from the Hugging Face
dataset `leolee99/NotInject` at revision
`847ae76cf8fea5ed325429e569ae8cfef022d2e0` (MIT licence), the over-defense
benchmark released with InjecGuard (arXiv:2410.22770). Each prompt carries
one, two or three trigger words such as *ignore*, in three splits of 113.
Every item is benign by the publisher's construction. `external/PROVENANCE.json`
records the source and revision. The layered detector's rule channels are
scored on it in `results/notinject.csv`.

## 4. Detector panel verdicts

`results/panel/verdicts.jsonl` holds one verdict per detector per item for the
six published and language-model detectors, on the probe set, NotInject,
the deepset test split and the two real corpora of section 5, 4842 verdicts
in all. `results/panel/guard_raw.jsonl`
holds the raw output behind each verdict: the label scores of every classifier
call and the answer of every language-model call. They were produced by phase
11 of the companion AutoGen study (`title36-autogen-guard-placement`,
`src/run_experiment.py`), whose model revisions and corpus revisions are
recorded in `results/panel/PANEL_SOURCE.json`. The verifier re-derives every
classifier verdict from its raw scores.

## 5. Real instruction-shaped benign text

`external/real_corpora.jsonl`, 261 items in two corpora, each item with its
source identifier. `external/PROVENANCE.json` records the revisions.

- **Role prompts (200).** Community prompts that instruct a model to take a
  role or do a task, from the Hugging Face dataset `fka/prompts.chat` at
  revision `fbea17f2045d053d27f1de9f099e9bfdbe55bf47` (CC0 1.0), 2169
  prompts in all. Community collections include jailbreak prompts, so a
  prompt is excluded when it matches a list of jailbreak markers (DAN,
  developer mode, jailbreak, no restrictions, ignore previous, uncensored and
  similar, listed in `fetch_panel_data.py` of the companion study). The
  filter excludes 58 prompts. From the rest, 200 are drawn with seed
  20260925. Every drawn prompt that contains a term that could signal a
  jailbreak (restrict, ignore, hack, weapon and similar) was read by one
  annotator. All read as benign role or task instructions, for example a
  game design brief that mentions weapon models.
- **Security abstracts (61).** Abstracts of arXiv papers about prompt
  injection (arXiv metadata, CC0 1.0), from the companion study's frozen
  snapshot. They describe attacks and quote attack phrasing and are benign.

Both corpora are benign by source and by the read above. There is no second
annotator.

## Derived result files

`results/` holds the raw output of every measurement phase, including
`guard_raw.jsonl` with all 546 individual guard calls and
`run_meta.json` with the detector configuration captured at run time.
`src/verify_numbers.py` re-derives every number in the paper from these files
with independently written code and exits non-zero on any disagreement.
